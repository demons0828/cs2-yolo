# 贝塞尔曲线鼠标移动模拟器 GUI 使用说明

## 概述

这是一个带有图形用户界面的贝塞尔曲线鼠标移动模拟器，可以模拟人类鼠标移动特征，包括手部抖动、速度变化和自然曲线轨迹。

## 功能特性

### 🎯 核心功能
- **贝塞尔曲线轨迹生成**：使用三次贝塞尔曲线生成平滑的鼠标移动轨迹
- **人类化模拟**：模拟手部抖动、速度变化等人类鼠标移动特征
- **实时轨迹显示**：可视化显示鼠标移动轨迹
- **参数实时调整**：通过滑块实时调整各种参数

### 🎮 控制面板
- **轨迹点数量**：控制轨迹的精细度（100-2000点）
- **噪声水平**：控制手部抖动的程度（0.0-2.0）
- **移动速度**：控制鼠标移动的速度（0.000001-0.0001）
- **显示轨迹图**：是否显示matplotlib轨迹图

### 📍 目标坐标设置
- **手动输入**：直接输入X、Y坐标
- **屏幕中心**：快速设置为屏幕中心位置
- **随机位置**：随机生成目标坐标
- **获取当前**：获取当前鼠标位置作为目标

### 📊 可视化功能
- **实时轨迹图**：显示完整的鼠标移动轨迹
- **起点终点标记**：绿色圆点标记起点，红色圆点标记终点
- **屏幕边界显示**：显示屏幕边界范围
- **实时鼠标位置**：显示当前鼠标位置

## 安装和运行

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动GUI
```bash
python start_gui.py
```

或者直接运行：
```bash
python gui.py
```

## 使用说明

### 基本操作流程

1. **启动程序**
   - 运行启动脚本，GUI界面会自动打开

2. **设置参数**
   - 调整轨迹点数量：数值越大轨迹越平滑
   - 调整噪声水平：数值越大抖动越明显
   - 调整移动速度：数值越小移动越慢

3. **设置目标坐标**
   - 手动输入坐标值
   - 或使用快捷按钮设置

4. **开始模拟**
   - 点击"开始模拟"按钮
   - 观察鼠标移动和轨迹图

5. **查看结果**
   - 右侧面板显示移动轨迹
   - 日志面板显示操作记录

### 参数说明

#### 轨迹点数量 (jindu)
- **范围**：100-2000
- **默认值**：1000
- **说明**：控制贝塞尔曲线的采样点数量，数值越大轨迹越平滑，但移动时间也越长

#### 噪声水平 (noise_level)
- **范围**：0.0-2.0
- **默认值**：0.58
- **说明**：控制手部抖动的程度，包括：
  - 基础噪声：随机抖动
  - 低频抖动：模拟手部自然抖动
  - 高频抖动：模拟鼠标传感器噪声

#### 移动速度 (speed)
- **范围**：0.000001-0.0001
- **默认值**：0.00001
- **说明**：控制鼠标移动的速度，数值越小移动越慢

### 快捷功能

#### 坐标设置
- **屏幕中心**：自动设置为屏幕分辨率的一半
- **随机位置**：在屏幕范围内随机生成坐标
- **获取当前**：获取当前鼠标位置

#### 操作按钮
- **开始模拟**：使用贝塞尔曲线平滑移动
- **停止模拟**：中断当前模拟过程
- **直接移动**：瞬间移动到目标位置
- **保存配置**：保存当前参数设置到配置文件

## 技术特性

### 贝塞尔曲线优化
- **自适应控制点**：根据移动距离自动调整曲线弯曲程度
- **距离感知**：短距离更直接，长距离更自然
- **方向感知**：考虑移动方向生成合适的控制点

### 噪声算法优化
- **自适应噪声**：根据移动距离调整噪声水平
- **多频段噪声**：模拟真实的手部抖动特征
- **平滑处理**：减少过度抖动，保持轨迹自然

### 性能优化
- **多线程处理**：GUI响应和鼠标移动分离
- **实时更新**：轨迹图实时更新
- **内存管理**：及时清理轨迹数据

## 配置文件

程序会自动创建和读取 `config.json` 配置文件，包含以下设置：

```json
{
    "mouse_movement": {
        "jindu": 1000,
        "noise_level": 0.58,
        "speed": 0.00001,
        "show_trajectory": false
    }
}
```

## 故障排除

### 常见问题

1. **GUI无法启动**
   - 检查是否安装了所有依赖
   - 确保Python版本 >= 3.7

2. **鼠标移动失败**
   - 检查是否有其他程序占用鼠标控制
   - 确保有足够的权限

3. **轨迹图不显示**
   - 检查matplotlib是否正确安装
   - 确保显示设备支持图形界面

4. **参数调整无效果**
   - 确保参数在有效范围内
   - 重新启动模拟查看效果

### 日志查看
- 程序会在控制台和GUI日志面板显示详细日志
- 日志文件保存在 `app.log`

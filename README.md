# 游戏辅助程序 - 健壮性改进版

这是一个基于YOLO模型的游戏辅助程序，用于检测和瞄准目标。经过重构后，代码具有更好的健壮性、可维护性和可扩展性。

## 🚀 主要改进

### 1. 代码架构改进
- **面向对象设计**: 将原来的过程式代码重构为面向对象架构
- **模块化设计**: 将功能分离到不同的类中，提高代码复用性
- **配置管理**: 使用JSON配置文件管理所有参数
- **类型提示**: 添加完整的类型提示，提高代码可读性

### 2. 错误处理和健壮性
- **异常处理**: 全面的异常捕获和处理机制
- **重试机制**: 自动重试失败的操作
- **资源管理**: 确保资源正确释放
- **日志系统**: 详细的日志记录和错误追踪

### 3. 新增功能
- **配置热重载**: 支持运行时修改配置
- **性能监控**: FPS显示和性能统计
- **线程安全**: 多线程环境下的安全操作
- **错误恢复**: 程序崩溃时的自动恢复机制

## 🛠️ 安装和配置

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置模型路径
编辑 `config.json` 文件，设置正确的模型路径：
```json
{
    "model_path": "yolo/yoloaimonnx/onnxmd/10w320v5.onnx"
}
```

### 3. 调整参数
根据需要调整检测参数：
```json
{
    "conf_threshold": 0.4,    # 置信度阈值
    "nms_threshold": 0.4,     # NMS阈值
    "input_size": [640, 640], # 输入图像大小
    "screen_crop_size": [1920, 1080] # 屏幕截取区域
}
```

## 🎮 使用方法

### 启动程序
```bash
python main.py
```

### 键盘控制
- **E键**: 瞄准最近的头部目标
- **Q键**: 退出程序
- **O键**: 切换T/CT阵营
- **I键**: 切换显示/隐藏检测框

## 🔧 核心类说明

### GameAssistant
主程序类，负责协调各个组件：
- 初始化所有子系统
- 管理程序生命周期
- 处理用户输入

### YOLODetector
YOLO检测器类：
- 模型加载和初始化
- 图像预处理和后处理
- 目标检测执行

### ScreenCapture
屏幕捕获类：
- 屏幕截图
- 区域裁剪
- 图像预处理

### AimController
瞄准控制器类：
- 目标选择算法
- 鼠标移动控制
- 瞄准精度优化

### MouseMovementSimulator
鼠标移动模拟器：
- 贝塞尔曲线轨迹生成
- 自然化鼠标移动
- 轨迹可视化

### ErrorHandler
错误处理工具：
- 异常捕获和处理
- 自动重试机制
- 错误日志记录

## 🐛 错误处理

### 常见错误及解决方案

1. **模型文件不存在**
   ```
   错误: 模型文件不存在: yolo/yoloaimonnx/onnxmd/10w320v5.onnx
   解决: 检查config.json中的model_path配置
   ```

2. **屏幕捕获失败**
   ```
   错误: 屏幕捕获失败
   解决: 检查屏幕分辨率设置和权限
   ```

3. **鼠标控制失败**
   ```
   错误: 鼠标移动失败
   解决: 检查鼠标权限和坐标范围
   ```
